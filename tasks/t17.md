title: GitHub Actions CI
status: todo
depends: t8, t14, t16

Steps:
- Create .github/workflows/ci.yml with two jobs:

    macos:
      runs-on: macos-latest
      steps:
        - uses: actions/checkout@v4 --recursive  (submodules for LuaJIT)
        - run: ./configure
        - run: make clean && make
        - run: make test
        - run: make coverage
        - run: make test-asan

    linux:
      runs-on: ubuntu-latest
      steps:
        - uses: actions/checkout@v4 --recursive
        - apt-get install libssl-dev
        - run: ./configure
        - run: make clean && make
        - run: make test
        - run: make coverage
        - run: make test-asan

- Trigger on: push to devel and main, pull_request targeting main
- Add a status badge to README.md (or create a minimal one if absent):
    [![CI](https://github.com/devhands-io/wrkx/actions/workflows/ci.yml/badge.svg)](...)

- Verify the mock server (mock_server.py) runs correctly in the GitHub Actions
  environment (python3 must be available; it is on both runners by default)

Acceptance:
- Push to devel triggers the workflow and both jobs go green
- Badge renders on the repo page
- A deliberate test failure (e.g. wrong assertion) makes CI go red
